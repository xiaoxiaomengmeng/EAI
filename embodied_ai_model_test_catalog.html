7. RTX 5090 环境注意事项

不要直接照搬旧项目里的 torch==2.0/2.1/2.2 + cu118/cu121 命令。当前机器应优先使用 torch==2.11.0+cu128，并确保 torch.cuda.get_device_capability() 返回 (12, 0)。
  1. 编译 flash-attn、xformers、自定义 CUDA op 时，确认 nvcc --version 是 CUDA 12.8。
  2. 设置 TORCH_CUDA_ARCH_LIST="12.0"。
  3. 尽量不要使用旧的预编译 CUDA wheel。
  4. 若某项目强依赖旧 CUDA 扩展，优先尝试关闭 flash-attn，改用 sdpa / eager。
  5. 必要时跳过 xformers，只跑 CPU / MuJoCo / SAPIEN 仿真部分，或使用 Docker 单独隔离旧环境。

8. 建议的阶段性测试计划

阶段 A：验证基础环境

  1. 验证 PyTorch / CUDA / RTX 5090：torch.cuda.is_available()、GPU 名称、计算能力。
  2. 跑 OpenVLA 最小动作预测 demo。
  3. 跑 LingBot-Depth 单张 RGB-D 示例。
  4. 跑 MuJoCo Menagerie 任意机器人 viewer。

阶段 B：验证经典机器人策略

  1. 跑 Diffusion Policy 的 PushT 或 RoboMimic 小任务。
  2. 跑 ACT 官方模拟任务。
  3. 尝试 LeRobot + SO-ARM100/SO-101 或 ALOHA 数据格式。

阶段 C：验证 VLA / 世界模型路线

  1. OpenVLA + LIBERO 微调权重。
  2. π0.5 + LeRobot 或 LIBERO。
  3. GR00T + LeRobot / Isaac Lab。
  4. LingBot-VLA / LingBot-VA 与 RoboTwin / LIBERO。
  5. RynnBrain / RynnWorld-4D / LingBot-World 作为 2026 新模型重点跟踪。
