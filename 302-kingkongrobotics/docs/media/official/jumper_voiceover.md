从小鸭子到小螃蟹，我在本地训练出了会走路的跳跳

今天给大家分享一个开源又好玩的项目，金钢科技的螃蟹机器人，跳跳。

说它之前，先聊一只小鸭子。我研究过开源双足机器人 Microduck，它先在电脑仿真里用强化学习练会走路，再把策略放到瑞芯微 RK3566 主控板上去跑。跳跳走的也是这条路，只不过两条腿换成了六条腿，还多了两只钳子。

跳跳重一点八公斤，有二十二个舵机，主控板升级成了瑞芯微 RK3576，自带六 TOPS 算力的 NPU。

它能走、能跳、会跳舞，钳子还能夹起一公斤的东西。

官网有个网页版模拟器，打开浏览器就能遥控它，还能换外观、换场景。

外观可以一句话交给 AI 来设计，社区里已经有不少有趣的作品。官方还在办开源动作大赛，要送出一百台跳跳。

技术上，训练用的是显卡并行仿真，几千只跳跳在同一块地板上一起练。部署这边，练好的策略会转换成 NPU 能直接跑的格式，同一套控制程序既能跑在主控板上，也能跑在网页和仿真里。

我用一块 5090 显卡在本地训练了四个小时，一共一万轮。练到两千五百轮左右，它就能稳稳走完每个回合，全程没有摔倒过。回放时能看到它三条腿一组、交替迈步，走得很稳。

下一步我打算把策略导出来，争取让它在真机上走起来。感兴趣的朋友可以去 GitHub 搜 KingKongRobotics 的 jumper，或者先去官网玩玩模拟器。
