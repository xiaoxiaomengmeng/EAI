## 纯文本解说文案（norm-01 LayerNorm，可脱离图片独立引用）

LayerNorm 只做一件事：把每一条样本当作独立的统计单元。它不借用同一个 batch 里其他样本的信息，只对这一条样本自己的 d 个特征求均值与方差，再用这两个统计量把这条样本拉回零均值、单位方差，最后把尺度的选择权通过一组逐特征可学习的缩放与平移交还给网络。

具体是三步。第一步求统计量：把这条样本的 d 个特征值取平均得均值 μ，再把各特征与均值的偏差平方后取平均得方差 σ²。第二步标准化：每个特征减去均值、除以标准差 √(σ²+ε)；分母里的 ε 是一个很小的常数，只为防止方差为零时除零，它不参与学习。第三步 affine：逐维度乘可学习的 γ、加可学习的 β；这一步看似多余却关键——归一化只是提供一个更好的起点，要不要把某种尺度恢复回来，由网络自己学出来。

看一个四维样本 [1, 3, 5, 7]：均值 4、方差 5，标准化后约为 [−1.34, −0.45, 0.45, 1.34]，关于零对称、散布被拉回单位尺度。正因为统计量只来自自己，LayerNorm 的行为不随 batch 大小改变，推理时 batch=1 也照样稳定——这也是它成为 Transformer 默认组件的原因。

## 1. 页 norm-01：LayerNorm 层归一化

### 1.1 必须画进去的事实（只讲 LayerNorm 自己）

**定义一句话**：LayerNorm（Ba et al., 2016）对**单条样本自己的 d 个特征**做归一化——把一条样本（一个 token 向量 / 一行隐藏状态）拉成零均值、单位方差，再乘回一组**可学习**的逐特征缩放/平移参数。它**不看 batch 里的其他样本**。

**数学形式（三步，海报的视觉中心）**：

1. **统计量**（沿特征维，对单条样本）：
   μ = (1/d) Σ_{i=1..d} x_i ； σ² = (1/d) Σ_{i=1..d} (x_i − μ)²
2. **标准化**：
   x̂_i = (x_i − μ) / √(σ² + ε) ，其中 ε ≈ 1e-5 是防除零的数值稳定常数（**不学习**）
3. **可学习 affine**：
   y_i = γ_i · x̂_i + β_i ，γ, β ∈ R^d 逐特征可学习

**三个要点（亮点三卡）**：
- **归一化轴 = 特征维**：统计量只对这一条样本的 d 个特征求，batch 内样本互不影响 → 推理 batch=1 也稳定。
- **三步流水线**：统计量 → 标准化 → 可学习 affine。
- **参数极少**：每特征一个缩放 γ、一个平移 β，共 2d 个；ε 是常数不学习。γ/β 的存在让网络在需要时能"学回"任意均值方差——归一化只是给一个更好的起点，不是硬约束。

**数值小例子（d = 4，让公式落地）**：
- 取一条样本 x = [1, 3, 5, 7]
- μ = 4 ；σ² = ((−3)² + (−1)² + 1² + 3²)/4 = 20/4 = 5 ；σ = √5 ≈ 2.236
- 标准化后（取 ε≈0、γ=1、β=0）：x̂ ≈ [−1.34, −0.45, 0.45, 1.34] —— 零均值、单位方差
- 可视化：上排 4 格原始值 → 下排 4 格标准化值，中间标 μ 与 σ²。

**性质（绿色面板三卡，仍只讲 LN 自身）**：
- **与 batch 无关**：统计量来自单条样本，训练/推理、batch 大小都不改变行为。
- **不抹掉尺度信息**：γ/β 可学习，网络可按需恢复任意均值/方差。
- **稳定训练**：把激活尺度控制在单位量级，缓解梯度消失/爆炸，是 Transformer 的默认组件。

## 2. 页 norm-02：BatchNorm 批归一化

**定义一句话**：BatchNorm（Ioffe & Szegedy, 2015）按**特征通道**统计：对**一个 batch 内所有样本、所有空间格**（卷积网络下）求均值/方差，归一化后做按通道的可学习 affine。推理时不用当前 batch，而用训练期累积的**运行统计**（指数移动平均）——训练/推理两套统计量，是 BN 最有辨识度的设计。

**数学三步**：① μ_c = (1/m) Σ x_i、σ²_c = (1/m) Σ (x_i − μ_c)²，i 跑遍通道 c 的 batch 与空间全部格、共 m 个；② x̂ = (x − μ_c)/√(σ²_c + ε)；③ y = γ_c x̂ + β_c（按通道一套）。推理式把 μ_c、σ²_c 换成 running mean / running var。

**轴图（panel2）**：两份样本网格（N=2、4 通道行 × 3 空间列）；橙色半透明横条**跨两份网格的同一通道行 c2** = 共享一组统计量的格范围；右注"换一个通道就重新算一组"。

**数值例子（panel3）**：通道 c 在 batch 四个样本上的值 [1, 3, 5, 7] → μ_c = 4、σ²_c = 5 → [−1.34, −0.45, 0.45, 1.34]。注：聚合的是 batch 维，不是单样本的特征维。

**亮点三卡**：统计轴=batch（按通道）/ 两套统计量（训练当前 batch、推理运行均值方差）/ 按通道 affine（每通道一个缩放一个平移，统计也每通道一组）。
**标题**：首行"BatchNorm 批归一化"；标语橙"训练时看 batch"+黑"，推理时看记忆"；三行"按通道跨 batch 与空间统计 | 训练/推理两套统计量 | 按通道 affine"。
**页脚**：批统计让训练更顺，也让行为系于 batch——/ 于是推理换用运行均值方差，把 batch 解耦掉。注：BatchNorm, Ioffe & Szegedy, 2015。

## 3. 页 norm-03：RMSNorm 均方根归一化

**定义一句话**：RMSNorm（Zhang & Sennrich, 2019）**不中心化**：不求均值、不减均值，只用这条样本特征的**均方根**（二阶矩）收尺度，再乘逐特征可学习缩放（通常无平移）。

**数学三步**：① ms = (1/d) Σ_{i=1..d} x_i²（均方）；② x̂_i = x_i/√(ms + ε)——全程没有减均值这一步；③ y_i = γ_i x̂_i，通常无 β。

**轴图**：橙半透明框罩住**某样本网格全部格**（范围与 LayerNorm 同），但右注强调"只算这些格的均方，不减均值、不中心化"。

**数值例子**：x = [1, 3, 5, 7] → ms = (1+9+25+49)/4 = 21、√21 ≈ 4.58 → x̂ ≈ [0.22, 0.65, 1.09, 1.53]；输出均值 ≈ 0.87 ≠ 0——**只把尺度收到单位、不保证零均值**，这是与中心化做法最直观的差别。

**亮点三卡**：统计量=均方（无中心化）/ 输出非零均值（只单位尺度）/ affine 通常只有缩放（无常数平移项）。
**标题**：首行"RMSNorm 均方根归一化"；标语橙"只管尺度"+黑"，不动中心"；三行"只算均方、不中心化 | 尺度不变、非平移不变 | 通常只缩放不平移"。
**页脚**：减均值不是必需，而是选择：RMSNorm 只保留尺度不变性，/ 用一步中心化换简洁。注：RMSNorm, Zhang & Sennrich, 2019。

## 4. 页 norm-04：InstanceNorm 实例归一化

**定义一句话**：InstanceNorm（Ulyanov et al., 2016）对**每个样本、每个通道**独立地在**空间维 (H, W)** 上统计：样本与通道两个下标决定一组 μ、σ²；affine 按通道（原文可选）。

**数学三步**：① μ_{n,c} = (1/HW) Σ_{h,w} x，σ²_{n,c} 同法用偏差平方；② x̂ = (x − μ_{n,c})/√(σ²_{n,c} + ε)；③ y = γ_c x̂ + β_c（按通道、可选）。

**轴图**：橙半透明框只罩**样本 1 网格的 c2 行**（其全部空间格）；右注"样本 2 与其余通道各自另算一组"。

**数值例子**：一张图某通道的四个空间像素值 [1, 2, 3, 10] → μ = 4、σ² = 12.5、σ ≈ 3.54 → x̂ ≈ [−0.85, −0.57, −0.28, 1.70]。注：聚合的是空间维，不是 batch。panel3 横幅终版文案"数值例子：单通道图的空间四像素"（15 汉字、w=427；初稿 20 字超宽溢出被裁）。

**亮点三卡**：统计轴=空间 (H, W) / 粒度=(样本, 通道) 对、不混 batch 信息、batch=1 也稳定 / 对比度被归一（逐实例对比度/风格信息被削弱）。
**标题**：首行"InstanceNorm 实例归一化"；标语橙"一张图一个通道"+黑"，空间维上聚合"；三行"逐样本逐通道 | 空间维聚合 | 不混 batch 信息"。
**页脚**：每张图校准自己的对比度，batch 大小就不再是问题——/ 这正是实例归一化给小 batch 的稳定性。注：InstanceNorm, Ulyanov et al., 2016。

## 5. 页 norm-05：GroupNorm 组归一化

**定义一句话**：GroupNorm（Wu & He, 2018）把通道分成 G 组，对**每个样本、每组**在**组内通道 + 全部空间格**上统计：不借 batch 信息、也不跨组；affine 仍按通道。

**数学三步**：① μ_{n,g} = (1/m_g) Σ x_i，i 跑遍样本 n 第 g 组的组内通道与全部空间格、共 m_g 个，σ²_{n,g} 同法；② x̂ = (x − μ_{n,g})/√(σ²_{n,g} + ε)；③ y = γ_c x̂ + β_c（按通道、非按组）。

**轴图**：样本 1 网格行 1-2 橙半透明框（组 1）、行 3-4 蓝半透明框（组 2）；右注"两组各算各的、互不混合"。

**数值例子**（1 样本 4 通道、G=2，每通道两值并入组展示）：组 1 [1, 2, 3, 4] → μ=2.5、σ²=1.25 → [−1.34, −0.45, 0.45, 1.34]；组 2 [10, 4, 1, 7] → μ=5.5、σ²=11.25 → [1.34, −0.45, −1.34, 0.45]。8 格一排、组括号在上。

**亮点三卡**：统计轴=组内通道+空间 / 粒度=(样本, 组)、不依赖 batch 大小 / G 是超参（组数少粗、多细；affine 按通道）。
**标题**：首行"GroupNorm 组归一化"；标语橙"通道分成组"+黑"，统计在组内"；三行"通道分 G 组 | 组内通道+空间聚合 | 不依赖 batch 大小"。
**页脚**：通道在组内互相帮忙，统计就不再依赖 batch——/ 组数是一个旋钮：粗还是细，由你拧。注：GroupNorm, Wu & He, 2018。

## 7. 数学字形与排版实测结论（cairosvg，2026-09-13 实测，非猜测）

**字体分工（铁律）**：
- **公式一律 Times New Roman 衬线栈**（`Times New Roman, Times, serif`）：μ σ γ β ε Σ √ − ≈ ² ᵢ ∫ 全通，且**真斜体可用**（`font-style="italic"`）。变量斜体、γ/β 橙色 #F97316、ε 蓝色 #2563EB。
- **中文注解一律 PingFang 栈**，独立 `<text>` 元素，**绝不与公式混在同一个 text 元素内**。PingFang 下希腊/数学符号**全豆腐**、无合成斜体。
- Menlo 等宽栈数学符号也全通，可作代码风公式备选；但**等宽栈内全角括号（）豆腐**（继承主系列 §5.3 坑），等宽行括号用 ASCII。

**仍豆腐 / 不可用（Times 下也豆腐）**：`∈ ℝ ⊙`。**组合字符 hat `x̂`(U+0302) 会侧挂成 `x^`**，禁用。

**手绘构件语法（本系列公式排版的唯一可靠手段，已实测通过）**：
- **分数线**：分子/分母各一个 `text-anchor="middle"` 的 text + 中间一条 `<line>`。
- **求和上下限**：Σ 主体一个大字号 text，上限/下限各一个**绝对定位**小字号 text，水平居中于 Σ 字形中心（不要放右侧）。
- **根号**：`<path d="M x,y l7,0 l6,16 l11,-34 l6,0">` 画勾 + 顶部一条 `<line>` 作 overline 盖住被开方式。
- **hat**：`<path d="M x,y l7,-9 l7,9">` 画小尖角，置于变量字形正上方约 6px；**不用组合字符**。
- **上标**：优先 Unicode `²`；一般上标/下标用小字号独立 text 绝对定位。
- **禁用字符**（继承主系列）：`→ × ≤ @ – µ(U+00B5)`；希腊 mu 用 `μ`(U+03BC)。箭头写 `->`，章节写"第 N 节"。

**排版间距坑（norm-01 首轮视觉门实测）**：
- **分式 bar 与根号 overline 垂直间距 <~10px 会并成"双线"**：分母含根号时，分数线与根号顶线至少留 14px（norm-01 终版 bar=632、overline=646）。
- **step 标题与公式垂直间距不足会让分子/hat 压标题**：标题基线到公式首行基线至少 +49px；含 hat 或上标时，hat/上标顶端不得高于标题基线 +15px。
- 多行公式面板行距（badge 间距）取 ~112px，单行公式面板可取 ~100px。
- **横幅 tab 必须先画面板白 rect、再画横幅**（z-order）：横幅 rect 压在面板 rect 之上才露出圆角 tab；若先画横幅，面板白 rect 会把横幅下半截盖掉（norm-02 首轮踩坑，三个横幅文字被切半）。
- **panel3 首排格子上方的小标签会撞横幅**：横幅底边 = rect_y+22（1140+22=1162），组括号标签等小字基线若 ≤1162 就压在绿横幅上（norm-05 初稿标签 y=1160 踩坑）；整块内容下移 16px（括号 1184、标签 1178）解决。
- **横幅宽度按实际字数现算，别信 brief 草稿字数**：norm-04 初稿把 20 汉字标题按 17 字估宽，"像素"二字溢出横幅外（白字落在暖白底上几乎隐形）；写 SVG 前逐字数一遍再套公式 CJK×1.0+拉丁×0.52 乘字号 +28+24。
