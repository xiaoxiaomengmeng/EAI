# Skills 索引

- 项目级 skill：`.qoder/skills/<name>/SKILL.md`；名字全小写 kebab-case、动词开头
- 跨项目复用：从 `~/.qoder/skills/<name>` 软链到本仓库源文件，只维护一份；同名时项目级优先
- 新建先用 /create-skill 生成模板

| 名字 | 用途 | 触发说法 |
|---|---|---|
| convert-webm-to-mp4 | Ubuntu 下 webm(VP8/VP9) 录屏转 H.264 mp4，含奇数分辨率抹偶 | 「webm 转 mp4」「录屏转 mp4」「视频格式转换」 |
