# MDP 原理（马尔可夫决策过程）

> 一份**纯原理**的 MDP 笔记：只讲概念与数学结构，不绑定任何具体代码或环境示例。

## 1. MDP 在描述什么问题

强化学习研究的是一类**序贯决策（sequential decision making）**问题：一个智能体（agent）处在某个环境（environment）里，反复做三件事——

```
观察当前局面 → 采取一个动作 → 环境变化并给出反馈（奖励）
```

这件事不是一次性的，而是**一连串**的：今天的动作会改变明天的局面，明天的局面又限制后天的选择。MDP（Markov Decision Process，马尔可夫决策过程）就是给这类"连环决策"问题的一套**标准数学语言**。

关键认知：**MDP 是"问题"，不是"算法"**。它只负责把问题写清楚；至于怎么解，是后面各种 RL 算法（Q-learning、DQN、PPO…）的事。

---

## 2. 五元组 \((S, A, P, R, \gamma)\)

一个 MDP 由五个要素完全确定：

| 符号 | 名称 | 含义 | 直觉 |
|---|---|---|---|
| \(S\) | 状态空间 | 所有可能"局面"的集合 | 棋盘的摆法、机器人的姿态 |
| \(A\) | 动作空间 | 智能体能做的所有选择 | 走哪一步、给多大扭矩 |
| \(P(s'\|s,a)\) | 转移概率 | 在 \(s\) 做 \(a\) 后落到 \(s'\) 的概率 | 世界的"物理规则"，可含随机性 |
| \(R(s,a)\) | 奖励函数 | 在 \(s\) 做 \(a\) 得到的即时评分 | 环境的"好坏信号" |
| \(\gamma \in [0,1)\) | 折扣因子 | 未来奖励的"汇率" | 越远的奖励越不值钱 |

前两个 \((S, A)\) 定义了"有哪些局面、哪些选择"；中间两个 \((P, R)\) 定义了"世界如何运转、如何打分"；最后一个 \(\gamma\) 定义了"如何权衡眼前与未来"。

---

## 3. 马尔可夫性：为什么可以"只看现在"

MDP 的名字里有 Markov，指的是**马尔可夫性（无记忆性）**：

\[ P(s' \mid s, a, \text{历史}) = P(s' \mid s, a) \]

即：**下一个状态只取决于"当前状态 + 当前动作"，与你是怎么走到当前的无关。**"现在"已经包含了预测未来所需的全部信息。

这条假设意义重大：它让智能体**只需盯住当前状态就能做最优决策**，不必背负全部历史，问题规模才可控。

> 现实中观测往往不满足马尔可夫性（信息不全），那就是 POMDP（部分可观测 MDP），常用"堆叠最近几帧"或 RNN 来补救。但入门阶段先假设完全可观测。

## 4. 策略、轨迹与回报

- **策略（policy）** \(\pi(a \mid s)\)：在状态 \(s\) 选择动作 \(a\) 的规则（可以是确定性的，也可以是概率分布）。策略就是 RL 最终要学的东西。
- **轨迹（trajectory）**：按策略走出来的一串经历 \(\tau = s_0, a_0, r_1, s_1, a_1, r_2, \dots\)。
- **回报（return）**：把一条轨迹上未来的奖励"折算到当下"求和：

\[ G_t = r_{t} + \gamma r_{t+1} + \gamma^2 r_{t+2} + \cdots = \sum_{k=0}^{\infty} \gamma^k r_{t+k} \]

**为什么需要折扣 \(\gamma\)（四个目的，重要性递增地叠加）：**

1. **让目标在数学上良定义（防发散）**：对不必然终止的 continuing 任务，若每步奖励非零且 \(\gamma=1\)，则回报 \(G_t=\infty\)，所有策略回报都是无穷、无法比较，目标函数失效。\(\gamma<1\) 让等比级数收敛、回报有界：\(G_t \le R_{\max}/(1-\gamma)\)。
2. **表达时间偏好（贴现）**：确定的眼前收益优于同等大小的遥远收益。\(\gamma\) 会**真实改变决策**——"立刻拿 10" vs "10 步后拿 11"：\(\gamma=1\) 选后者（\(11>10\)），\(\gamma=0.9\) 选前者（\(11\times0.9^{10}\approx3.8<10\)）。
3. **对未来不确定性做对冲**：把 \(\gamma\) 看成每步的"存活概率"，\(1-\gamma\) 即"任务终止概率"；打折 = 按"未来还能否兑现"对远期奖励取期望，不把宝押在未必存在的远端。
4. **保证算法收敛 + 限定有效视野**：Bellman 算子在 \(\gamma<1\) 时是**收缩映射（contraction）**，由不动点定理保证 value/policy iteration 收敛到**唯一** \(V^*\)；同时 \(\gamma\) 决定"多远的事还算数"，有效视野约 \(1/(1-\gamma)\)。

| \(\gamma\) | 有效视野 \(\approx 1/(1-\gamma)\) | 性格 |
|---|---|---|
| 0.9 | ~10 步 | 短视，近期奖励主导 |
| 0.99 | ~100 步 | 平衡（常用） |
| 0.999 | ~1000 步 | 远视，远期噪声也计入 |

### 关键算例：永续 +1 流的现值 \(=1/(1-\gamma)\)

设"每步恒 +1、永不停止"的 continuing 任务，取 \(\gamma=0.9\)：

\[ G = \sum_{k=0}^{\infty}\gamma^k = 1 + 0.9 + 0.81 + 0.729 + \cdots = \frac{1}{1-\gamma} = \frac{1}{1-0.9} = 10 \]

这个 **10** 有三层等价读法：

- **现值（present value）**：未来有**无穷多个** +1，不打折加起来是 \(\infty\)；打折后被压缩成一个有限数 10，即"站在当下，未来全部 +1 值多少"。
- **等价步数**："按 0.9 打折拿永远" = "不打折只拿 10 步 +1"（因为 \(G=10\)）。即 \(\gamma=0.9\) 下"永远"只相当于约 10 步之重——这正是有效视野 \(1/(1-\gamma)\) 的含义。
- **上界（满分）**：任何"每步奖励 \(\le 1\)"的策略，其 return 都 \(\le 10\)。折扣把回报压进有限区间 \([0,10]\)，策略之间才可比较、才可优化。

> **澄清**：对**必然终止的 episodic 任务**（如"到达终点即结束"），\(\gamma=1\) 时回报也有限，"防发散"这条不成立；但实践中仍常用 \(\gamma<1\)，因为时间偏好、终止不确定性、收缩收敛与可控视野（目的 2/3/4）依旧生效。**别把折扣只理解成"防无穷"**——它同时是"智能体目光长短"的那一个旋钮。

## 5. 价值函数：给"局面"打分

为了比较"哪个局面好、哪个动作好"，定义两个函数：

- **状态价值** \(V^{\pi}(s) = \mathbb{E}[\,G_t \mid s_t = s\,]\)：从 \(s\) 出发、之后一直按 \(\pi\) 走，期望能拿多少折扣回报。
- **动作价值** \(Q^{\pi}(s,a)\)：在 \(s\) **先强制做 \(a\)**、之后按 \(\pi\) 走的期望回报。

二者关系：\(V\) 是 \(Q\) 按策略的加权平均，\(Q\) 是 \(V\) 往前看一步。有了 \(Q^*\)（最优动作价值），最优策略就是"每步贪心选 \(Q\) 最大的动作"。

**RL 的总目标**：找到最优策略 \(\pi^*\)，使价值最大：\(\pi^* = \arg\max_\pi V^{\pi}(s)\)。

---

## 6. Bellman 方程：价值的递归结构

MDP 最漂亮的性质是价值满足**递归（自洽）方程**——"今天的价值 = 即时奖励 + 打折的明天价值"：

**Bellman 期望方程**（评估一个给定策略 \(\pi\)）：

\[ V^{\pi}(s) = \sum_a \pi(a \mid s) \sum_{s'} P(s' \mid s, a)\,\big[\, R(s,a) + \gamma\, V^{\pi}(s') \,\big] \]

**Bellman 最优方程**（求最优价值 \(V^*\)）：把"按 \(\pi\) 加权求和"换成"取最大"：

\[ V^{*}(s) = \max_a \sum_{s'} P(s' \mid s, a)\,\big[\, R(s,a) + \gamma\, V^{*}(s') \,\big] \]

直觉：你不需要一次性看完整条无限长的轨迹，只要相信"明天的价值已经算好了"，就能从"即时奖励 + 打折的明天"推出"今天的价值"。这个**bootstrap（自举）**思想是几乎所有 RL 算法的内核。

## 7. MDP 与 RL 的分工

同一个 MDP，解法取决于你**知不知道 \(P\) 和 \(R\)**：

| 情形 | 方法 | 说明 |
|---|---|---|
| \(P, R\) 已知 | **动态规划**（value iteration / policy iteration） | 直接用 Bellman 方程迭代求解，"上帝视角" |
| \(P, R\) 未知（真实世界） | **强化学习**（Q-learning / DQN / PPO…） | 靠与环境交互采样出的经验，去估计价值、改进策略 |

所以一句话概括：**RL = 在不知道转移和奖励模型的前提下，去解一个 MDP。** 各种 RL 算法的差别，只是"用什么方式去逼近 Bellman 方程 / 去改进策略"。

---

## 8. 建模的艺术（真正难的地方）

把一个问题写成 MDP 时，几个选择直接决定成败：

- **状态设计**：信息够不够（马尔可夫性）、维度高不高。状态太差，再好的算法也学不会。
- **奖励设计**：奖励是唯一的"目标说明书"。设计不当会出现 reward hacking（智能体钻奖励的空子）；太稀疏则学不动。
- **\(\gamma\) 选择**：决定智能体短视还是远视。
- **episodic vs continuing**：任务是否有自然终点（一局棋会结束 vs 控制任务永续）。

---

## 一句话总结

MDP 用 \((S, A, P, R, \gamma)\) 把"连环决策"写成数学；马尔可夫性让"只看现在"成为可能；回报与价值函数给局面打分；Bellman 方程给出价值的递归结构；而 RL 算法负责在 \(P, R\) 未知时把它解出来。
