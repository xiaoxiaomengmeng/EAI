## 工作习惯
- 流程约束：
  - 模型复现按验证阶梯推进：单步推理 → 官方 benchmark → 自定义仿真闭环，前一阶通过才进下一阶
  - 重视复现链路的每一处约定对齐（坐标系、四元数顺序、归一化统计、动作空间 EE/关节、单位与夹爪极性）
  - 关注零样本泛化验证，而非仅微调/采数据
  - 解决问题时喜欢参考已有实现（如 aero-hand-open/ros2）
  - 环境安装等操作常亲自执行，由助手提供命令并核对结果
- 工程约定：
  - 项目 README 先讲怎么跑，再讲模型输入/输出与控制方式；每个验证阶段写清目的、命令、场景、判据和坑总结
  - 权重统一放 `~/ws/models/` 软链，用本地源码离线加载（不依赖 trust_remote_code 联网）
  - 关注磁盘占用，训练产物只保留关键 checkpoint
- 红线：
  - 删除、覆盖等不可逆操作需先确认；修改重要文件前习惯先保留副本
  - 不改上游子模块，兼容问题在封装层 shim 解决；装源码包用 `--no-deps`，保护已验证的 torch/CUDA
